# 大字配图封面规范

## 稳定的视觉特征

参考 assets/style-reference.png：大标题在上，主题插画在下，背景留白充足；标题是第一视觉焦点，插画是第二焦点。它是一张封面，不是六页图文的压缩版。

- 默认竖版宽:高=3:4，上部约40%–55%给文字，余下组织一个主要插画场景；按标题长短微调。
- 主标题用粗黑体类字体，关键词最大，优先1–3行，缩略图仍可辨认。建议精炼至4–12个汉字或相当长度，不为达字数损伤准确性。
- 小标签可用“一篇看懂”“原理拆解”等但不强制；副标题可用一句具体问题，也可省略。全图一般不超过三层文字。
- 四边留约6%–8%安全边距；局部装饰可出血，文字和关键主体不可截断。
- 默认采用轻微纸张质感的纸艺/柔和立体插画，柔和阴影、明确形体；用户另指定画风时尊重。
- 主体按文章选：标签管理用卡片与便签，流程用手册与步骤；机器人不是固定主角。
- 背景简洁，避免杂乱纹理、霓虹代码雨和无关装饰；色彩建立层级，不承担未经解释的科学含义。

## 可变配色

用户色名/色值优先；未指定时按主题选择。以下是可选搭配，不是固定主题规则。

| 背景示例 | 大字 | 插画与点缀 |
|---|---|---|
| 暖米白 #F6F0E3 | 近黑 #171717 | 钴蓝＋少量黄绿或橙 |
| 浅粉 #F7E4E8 | 深梅紫 #3B2233 | 奶白、珊瑚、少量莓红 |
| 浅蓝 #E5F0F8 | 深海军蓝 #142D4E | 钴蓝、米白、少量橙 |
| 浅薄荷 #E5EFE8 | 深墨绿 #173C30 | 米白、森林绿、少量黄 |
| 墨绿 #163D32 | 暖白 #FFF7E8 | 薄荷、奶油黄、少量橙 |

一个主背景、一个主文字色、少量点缀即可。用户要求白底黑字时尊重，不因示例有彩色就自行加色。

## 生图提示词结构

按实际任务填写具体值；调用前消除未填项。字体和中文文案须可读，配色与主题对应。

1. 用途：小红书文章封面，面向普通读者，成品图片而非设备样机。
2. 画布：PORTRAIT，明确 width:height = 3:4，请求像素；用户明确横版时换成 LANDSCAPE 与4:3。
3. 主题与插画：准确主题＋一个具象场景，不引入原文没有的能力或夸大效果。
4. 构图：超大主标题文字区＋一个插画区＋留白与安全边距。
5. 配色：明确背景、文字、点缀色，用户指定色优先。
6. 精确文字：逐条列出小标签、主标题、副标题，说明哪个最大、如何换行；无须字段省略。
7. 风格：纸艺/柔和立体、简洁科普，或用户指定风格。
8. 限制：无额外文字、无水印、无二维码、无密集正文，不裁字。

使用参考图片时追加：这张图仅提供构图、字重和纸艺质感，不是要复制其主题。替换所有主题文案与主体，背景以本提示词指定色为准。

## 改图保留项

- 只改背景：以当前成品为编辑目标；保持标题、引子、主体、比例和构图，仅调整背景及必要对比色。
- 横改竖或竖改横：重新组织文字与插画，不裁切或拉伸；文案与主题保持。
- 改主题：生成新的主题插画和文字，保留大字配图视觉系统；不是旧图换标题。
