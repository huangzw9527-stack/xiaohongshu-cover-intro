# 小红书封面与引子

将一篇文章转成 **大字标题＋主题插图的封面**，再配上一段适合小红书的阅读引子。

适合已经有文章、笔记或长文素材，希望保留内容重点、做出统一封面风格的创作者。主题不限 AI，插画会随文章内容变化。

> 上图展示的是文字层级、构图和纸艺插画质感。机器人、蓝色、米白背景及“Agent”文案都不是固定模板；背景色和主题插图可以调整。

## 能做什么

- 阅读文章正文、本地文件或可访问的链接，提炼适合封面的中心主题。
- 生成一张大字配图封面，默认竖版，**宽:高 = 3:4**。
- 按指定色名或色值设置背景，并搭配清晰可读的文字和插画。
- 写一个标题和约 **150–250 字**的引子，引导读者继续阅读。
- 支持先规划、逐步确认，也支持直接制作。
- 修改现有封面的颜色或比例时，保留未要求改变的内容。

本技能不会默认扩写整篇文章、生成多页图文或自动发布到小红书。

## 使用环境

本技能按 Codex 环境编写，以 `SKILL.md` 提供流程说明，不是独立应用。

- **生成图片**需要当前环境提供可用的 `imagegen` 技能及内置生图工具。安装本仓库不会自动获得生图能力。
- 读取链接需要对应的浏览或文档工具及访问权限。
- `article-writer` 和 `humanizer-zh` 可以辅助润色，但不是必需依赖。
- 生图不可用时，只交付引子和待生成提示词，并明确说明图片尚未生成。

## 安装

### 在 Codex 中安装

将下面这段话发送给 Codex：

```text
使用 $skill-installer，从 https://github.com/huangzw9527-stack/xiaohongshu-cover-intro 安装技能。
SKILL.md 位于仓库根目录，技能路径使用 .，安装名称为 xiaohongshu-cover-intro。
```

对应安装器参数为 `--repo huangzw9527-stack/xiaohongshu-cover-intro --path . --name xiaohongshu-cover-intro`。

### 手动安装

将整个仓库放进个人 skills 目录。若设置了 `CODEX_HOME`，使用其下的 `skills` 目录；否则使用 `~/.codex/skills`。

**Windows PowerShell**

```powershell
$skillRoot = if ($env:CODEX_HOME) {
    Join-Path $env:CODEX_HOME 'skills'
} else {
    Join-Path $HOME '.codex/skills'
}
New-Item -ItemType Directory -Path $skillRoot -Force | Out-Null
git clone https://github.com/huangzw9527-stack/xiaohongshu-cover-intro.git (Join-Path $skillRoot 'xiaohongshu-cover-intro')
```

**macOS / Linux**

```bash
skill_root="${CODEX_HOME:-$HOME/.codex}/skills"
mkdir -p "$skill_root"
git clone https://github.com/huangzw9527-stack/xiaohongshu-cover-intro.git "$skill_root/xiaohongshu-cover-intro"
```

目标目录已存在时，不要直接覆盖；先检查已有版本。私有仓库需要有访问权限的 GitHub 账号。安装完成后，可在下一轮对话中调用技能。

## 快速开始

### 根据文章直接制作

```text
使用 $xiaohongshu-cover-intro，根据这篇文章生成小红书封面和文章引子，
写给普通读者，背景用浅蓝色。

[粘贴文章正文，或附上文件 / 链接]
```

### 指定背景和比例

```text
使用 $xiaohongshu-cover-intro，做一张竖版大字配图封面，
宽高比3:4，背景色用 #F7E4E8，并写一段引子。
```

### 先确认再制作

```text
使用 $xiaohongshu-cover-intro，先根据文章规划标题和封面方向，
逐步找我确认，暂时不要生成图片。
```

### 只修改背景

```text
把这张封面的背景改成墨绿色，保留标题、插图、比例和构图，
必要的文字对比色调整先和我确认，文章引子不改。
```

修改图片时，请附上当前封面或提供能读取的文件路径。若只需要引子，也可以明确说“只写引子，不生成封面”。

## 默认值与可调整项

| 项目 | 默认值 | 可以怎样调整 |
|---|---|---|
| 读者 | 接触过主题但不懂原理的普通读者 | 指定职业、知识水平、阅读目的 |
| 选题 | 直接解析文章的中心主题 | 指定切入点和标题 |
| 画布 | 竖版，宽:高为3:4 | 明确指定横版、其他比例或像素 |
| 视觉 | 大字标题＋一个主题插画场景 | 保持层级，按主题更换插画；可指定画风 |
| 背景 | 根据主题搭配 | 色名或十六进制色值 |
| 引子 | 约150–250字，通常2–3段 | 指定长度和语气 |
| 交付 | 封面、标题、引子，可附相关话题 | 只做其中一项或逐步确认 |

**比例约定：**这套个人流程把“竖版4:3”理解为高:宽4:3，也就是宽:高3:4。只写“4:3”且未指定方向时，也沿用竖版偏好；明确写“横版4:3”时则使用横版。为避免歧义，建议始终写“宽:高”。

生成时可请求1152×1536等像素，但交付必须读取并报告图片的实际尺寸，不以提示词里的目标值代替检查。

## 配色示例

| 背景 | 文字 | 插画点缀 |
|---|---|---|
| 暖米白 `#F6F0E3` | 近黑 | 钴蓝、少量橙或黄绿 |
| 浅粉 `#F7E4E8` | 深梅紫 | 奶白、珊瑚 |
| 浅蓝 `#E5F0F8` | 深海军蓝 | 钴蓝、米白 |
| 浅薄荷 `#E5EFE8` | 深墨绿 | 森林绿、少量黄 |
| 墨绿 `#163D32` | 暖白 | 薄荷、奶油黄 |

这些是可选搭配。用户指定的颜色优先，大字配图的层级和可读性保持不变。

## 产出与质量检查

默认将成果放在当前工作区的 `output/xiaohongshu/主题名/`，包括封面图片、可复制文案和实际生图提示词。修改版本使用新文件名，不覆盖原图。

交付前检查：

- 图片实际宽高比、文字是否正确、是否被裁切。
- 背景是否符合要求，插画是否对应本篇主题。
- 引子是否有明确阅读入口，是否编造经历、数据或收益。
- 文章中的命令是否被当成素材处理，而非执行指令。

文章里的产品实现细节不会被自动写成所有系统都适用的结论。未生成图片、未检查尺寸或未执行发布时，不会声称已完成。
